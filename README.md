# Инвентаризация

Учёт техники и имущества небольшой компании для Windows: склад, сотрудники, накладные, заказы по счетам на оплату и расходники.
Накладные и счета **распознаются локальным ИИ бесплатно и без интернета**: загружаешь фото или PDF, получаешь заполненную таблицу.

C# · .NET 10 · WinForms · SQLite · Ollama

## Возможности

- **Склад**: у каждой вещи своя карточка с инвентарным и серийным номером, ценой, компанией, фото и полной историей.
- **Движение вещей**: выдать, вернуть, передать другому сотруднику, отправить в ремонт, списать.
- **Сотрудники**: что за кем числится; импорт и экспорт CSV.
- **Приход по накладной**: перетаскиваешь фото или PDF, ИИ распознаёт номер, дату, поставщика, БИН и позиции. Остаётся проверить и нажать «Принять».
  Вещи можно сразу выдать нужным сотрудникам.
- **Пачка старых накладных**: файлы или целая папка уходят в очередь, распознаются в фоне, потом их проверяют по одной.
- **Заказы по счетам на оплату**: у каждой позиции указано, для кого она; статусы «Ждёт оплаты → Оплачен → Получен».
  Когда пришла накладная, программа сама сопоставляет её со счётом и выдаёт вещи получателям.
- **Расходники** (бумага, картриджи, кабель): учёт остатком, минимальный остаток с подсветкой, журнал движений.
- **Документы**: акт выдачи в PDF, QR-наклейки (лист A4 или одиночные), выгрузка в Excel.
- **Бэкап**: ручной и автоматический раз в сутки, восстановление из zip.
- Компании, поиск по всему, перетаскивание файлов, запуск только одной копии программы.

## Распознавание

| Способ | Цена | Интернет | Качество |
|---|---|---|---|
| **Ollama** + `qwen3-vl:4b-instruct` (по умолчанию) | бесплатно | не нужен | хорошее, ~10–20 с на страницу с видеокартой 6 ГБ |
| Windows OCR (запасной) | бесплатно | не нужен | таблицы читает слабо |
| Claude API | платно, нужен ключ | нужен | лучшее |

Способ выбирается в «Сервис → Настройки». Если Ollama не запущен, программа запускает его сама, а если не получится, распознаёт через Windows OCR.

## Установка

1. Скачайте `Inventory-Setup-*.exe` и запустите. Права администратора не нужны, .NET ставить не нужно.
2. Оставьте галочку **«Установить бесплатный ИИ…»**: установщик скачает и поставит [Ollama](https://ollama.com) (≈1,8 ГБ).
3. При первом запуске программа предложит скачать модель ИИ (≈3,3 ГБ, один раз). Прогресс виден, прерванная загрузка потом продолжится.

Данные хранятся в `%AppData%\Inventory`: база SQLite, файлы накладных, бэкапы, логи. При удалении программы они **не удаляются**.

## Сборка из исходников

Нужны: .NET SDK 10, Windows 10 1809+. Для установщика нужен ещё [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```powershell
dotnet build
dotnet test                                                  # xUnit, 44 теста
powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1
```

Скрипт прогоняет тесты, публикует self-contained сборку в `publish\` и собирает `dist\Inventory-Setup-<версия>.exe`.

## Структура

```
src/Inventory/
  Data/            SQLite + Dapper: репозитории, миграции (schema_version)
  Models/          сущности
  Services/
    Recognition/   Ollama, Windows OCR, очередь распознавания
    Claude/        клиент Claude API
    Documents/     акт PDF, QR-наклейки, Excel
  UI/              окна WinForms (интерфейс написан кодом, без дизайнера)
tests/Inventory.Tests/
installer/         скрипт Inno Setup
scripts/           сборка установщика
```
